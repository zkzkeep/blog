## 一、先有一棵树，再长叶子

规则只有三条：

- 每天一个点

运维不需要像继保专业那样会整定、会调试，但目标很明确：**看得懂、会判断、操作不出错**。

## 二、Day 1：二次回路识图

### 1. 四种图，各管一件事

| 图 | 看什么 | 什么时候用 |
|---|---|---|
| 原理图 | 一次、二次画在一起，看整体功能 | 理解原理 |
| 展开图 | 按回路拆开：交流电流、交流电压、控制、信号 | 分析回路、查缺陷，最常用 |
| 屏面布置图 | 装置、压板、空开在屏上的位置 | 现场找东西 |
| 安装接线图 / 端子排图 | 每根线从哪个端子接到哪个端子 | 查线、做安措 |

对运维来说，最该练熟的是**展开图**和**端子排图**。展开图用来弄懂回路为什么这样接，端子排图用来在现场找到那根线。

### 2. 回路编号：背下来，读图快一倍

**交流回路**的编号规律比较统一：

- 电流回路：`A411`、`B411`、`C411`、`N411`，数字在 400～599 之间
- 电压回路：`A630`、`B630`、`C630`，数字在 600～799 之间
- `N600` 是 PT 二次的中性线，也就是 PT 回路"一点接地"的那个点

**直流回路**的常见规律如下，具体以本站图纸首页的编号说明为准：

- `101`、`201`：正电源（+KM）
- `102`、`202`：负电源（-KM）
- 合闸回路一般在 103 附近，跳闸回路一般在 133 附近
- 百位数不同，代表来自不同的电源或回路组

**设备代号**各设计院写法略有差异，常见的有：

- `1n`：屏上第 1 个装置；`1n3`：它的 3 号端子
- `1LP1`：第 1 个装置的第 1 块压板（LP 是连接片）
- `1D`、`1ID`、`1UD`：端子排，I 表示电流，U 表示电压
- `QF` 断路器，`YT` 跳闸线圈，`YC` 合闸线圈

### 3. 读展开图的四条规矩

1. **所有触点都按"常态"画**：线圈不带电，开关在分闸位置。所以图上画成"常开"的断路器辅助触点，开关合着的时候其实是**闭合**的。我以前就在这里搞反过。
2. **先找电源，再顺着走**：从 +KM 出发，一路经过哪些触点和线圈，最后回到 -KM。
3. 先交流后直流，从上到下，从左到右。
4. 端子排图用**相对编号法**：A 端子旁边标的是对端 B 的编号，反过来也一样。在现场按这个编号就能顺着线找过去。

### 4. 实战：读一条跳闸回路

简化后，一条跳闸回路从正电源到负电源依次是：

```
+KM (101)
  │
保护出口触点      ← 保护动作后闭合
  │
出口压板 LP       ← 退出就跳不了
  │
操作箱 TBJ        ← 跳闸保持，同时启动防跳
  │
QF 常开辅助触点   ← 开关合位时闭合
  │
跳闸线圈 YT       ← 通电，开关跳开
  │
-KM (102)
```

**为什么要串一个 QF 常开辅助触点？** 开关跳开以后，这个触点跟着断开，把线圈电流切掉。没有它，跳闸线圈会一直带电，最后烧掉。

顺着这条回路，可以把三个天天见、却不一定说得清的信号搞明白：

- **HWJ（合位监视）**：接在跳闸回路里，经过 QF 常开辅助触点。开关在合位时它励磁，同时也说明跳闸回路是通的。
- **TWJ（跳位监视）**：接在合闸回路里，经过 QF 常闭辅助触点。开关在分位时它励磁。
- **控制回路断线**：HWJ 和 TWJ **都不励磁**时发出。正常情况下两者必有一个励磁，都不励磁，就说明回路断了，或者失去了控制电源。

**500kV 的特点**：开关分相操作，每相有**两组跳闸线圈**，分别接两组直流电源，对应第一套和第二套保护。一套回路出了问题，另一套照样能跳。

## 三、顺带补的一课：CT 二次回路

识图时绕不开 CT 回路，就一起记下来。

**CT 二次为什么不能开路？** 正常运行时，二次电流产生的磁通会抵消一次电流的磁通，铁芯里只剩很小的励磁磁通。二次一开路，这个抵消作用没了，一次电流全部变成励磁电流，铁芯深度饱和。二次绕组会感应出很高的尖峰电压，危及人身和设备，铁芯还会过热。

**为什么只能一点接地？** 接地是为了防止一次高压窜进二次、危及人身。但如果有两个接地点，两点之间的地电位差会在回路里产生额外电流，流进保护装置，可能引起误动。反措的要求是：

- 几组 CT 并在一起的公用回路，在保护屏内一点接地
- 跟别的 CT 没有电气联系的独立回路，在开关场一点接地

**3/2 接线的"和电流"**：线路保护用的电流 = 边开关 CT + 中开关 CT，两组 CT 的二次并接在一起。所以一台开关转检修、线路继续运行时，必须把检修开关的 CT 二次从和电流回路里隔离出来，顺序是**先短接 CT 侧，再断开连片**。否则检修人员给这组 CT 做试验时，电流会串进正在运行的线路保护，可能造成误动。

这条安措我以前是照票执行，今天才真正明白为什么要这样做。
