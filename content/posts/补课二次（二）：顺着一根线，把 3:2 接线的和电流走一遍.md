上一篇学的是二次回路识图，写到 CT 那段时，我自己心里其实还是迷糊的：和电流到底在哪里"和"？中开关检修时，隔离 CT 要动哪几个端子？N 线要不要断？

光看书想不通，这次就下到保护室，对着一面 500kV 线路保护屏的端子排，一根线一根线地看线号，最后再翻出图纸核对。这篇把这一天的收获整理下来。

> 说明：文中的端子号、线号都来自我们站的一面线路保护屏，别的站编号不一样，一切以本站图纸为准。

## 一、先把结论放前面

- 3/2 接线的线路上没有单独的 CT，**线路电流 = 边开关 CT 电流 + 中开关 CT 电流**，这就是"和电流"。
- **CT 二次回路是一个圈**：电流从 CT 出来，穿过保护、安稳、录波，再经 N 线回到 CT 自己。
- 我们站的两套保护，"和"的位置不一样：**第一套在进装置之前、在端子排上并接**；**第二套两组分别进装置，出来以后才用黄色连接片并接**。
- 中开关检修时隔离它的 CT：**A、B、C、N 四个端子都要处理，先短电缆侧，再断连片**；短接点一定要在电缆侧，汇合点和黄色连接片一律不动。
- 和电流在这面屏上串接的顺序是 **保护 → 安稳 → 录波**。

## 二、为什么要"和电流"

![图1：3/2 接线一个串](images/fig1-32-string.png)

一个完整串有三台开关：两台边开关（5031、5033）和一台中开关（5032）。本线路挂在 5031 和 5032 之间，流进线路的电流一部分从 5031 来，一部分从 5032 来。

线路本身没有 CT，所以线路保护只能把两台开关的 CT 电流加起来用。

## 三、先搞懂 CT 的脾气

后面所有的问题，归根到底都是这一条：**CT 是电流源。**

一次有电流，CT 就一定要往外推出一个固定大小的二次电流，大小由一次电流和变比决定。至于它两端的电压有多高，取决于这股电流流过的回路阻抗：

| 二次回路状态 | 回路阻抗 | 二次电流 | CT 两端电压 |
|---|---|---|---|
| 短接 | 接近 0 | 正常流 | 接近 0 |
| 接保护装置 | 很小 | 正常流 | 几伏 |
| **开路** | 无穷大 | **流不出来** | **极高** |

所以：

- **CT 不怕短路**，短接本来就是它最舒服的状态；**PT 才怕短路**。
- **CT 怕开路**。开路以后没有二次电流去抵消一次电流的磁通，铁芯深度饱和，磁通剧烈变化，再经过上千匝二次绕组"放大"，就是上千伏的尖峰电压。
- 开路不一定是把线拆光，**任何一相断开**都算：连片没压紧、端子螺丝松了、芯线断了都是。

我当时还问了一个问题：CT 一次也是 500kV，一次电压是不是很高？

不是。500kV 是导线**对地**的电压。CT 一次绕组是**串**在线路里的，它两端之间只隔着一小截导体，电压只有毫伏级。粗算一下：变比 2000/1，二次回路阻抗约 10Ω，二次电压 1A × 10Ω = 10V，折算到一次只有 10V ÷ 2000 = 5mV。

这跟站在高压线上的小鸟是一个道理：两只脚踩在同一根导线上，中间几厘米导线的压降只有几毫伏，按小鸟身体 1000Ω 算，流过它的电流只有几微安。

一句话：**PT 并联测电压，CT 串联测电流。**

## 四、现场：第一套保护

### 端子排上的线号

![照片1：第一套保护的电流端子](images/01-set1-terminals.jpg)

线号标签怎么读，以 `WXB31-101/1 A111` 为例：`WXB31-101` 是电缆编号，`/1` 是第 1 芯，`A111` 是回路号。

| 端子 | 回路号 | 来自 |
|---|---|---|
| 1ID1 | A111 | 5031 CT |
| 1ID2 | A181 | 5032 CT |
| 1ID3 | B111 | 5031 CT |
| 1ID4 | B181 | 5032 CT |
| 1ID5 | C111 | 5031 CT |
| 1ID6 | C181 | 5032 CT |
| 1ID7 | N111 | 5031 CT |
| 1ID8 | N181 | 5032 CT |

两组 CT 的每一相**各占一个端子、各有一个连片**，而且是交替排列的，111、181、111、181……相邻两个端子就属于不同的开关。做安措时，看错一个就会拆到运行的那一组。

还有一点：我们站电流回路用的是 111、181 这种编号，**不是**书上常见的 A411、400～599 那一套；电压回路倒是用的 A630、N600。编号规律只能参考，以本站图纸首页的说明为准。

### 对照图纸

![照片：第一套保护电流回路图纸（局部）](images/07-set1-schematic-crop.jpg)

图纸把整条路说清楚了：

1. 5031 的 A111 进 1ID1，5032 的 A181 进 1ID2，**两个端子在屏内侧并在一起**，再进装置 1n309。
2. 装置里只有一个 A 相通道，1n309 进、1n310 出。**进装置的时候已经是和电流了。**
3. 出来经 1ID10，编号变成 A112，送往下一个装置。回路号从 111 变成 112，就表示已经穿过了一个装置。
4. N 线同理：N111（1ID7）和 N181（1ID8）并接，经过装置的 N 相通道（1n316、1n315），从 1ID13 以 N112 接出。
5. **接地符号画在 1ID8**，也就是 N 线汇合处。这就是和电流回路的一点接地，符合"公用回路在保护屏内一点接地"的反措要求。

图纸上 A112 原本印的是去"故障录波器柜"，旁边有手写改成了"安稳主机A"。到现场核实，现在的顺序是**先到安稳，再到录波**。

## 五、现场：第二套保护

![照片2：第二套保护的电流端子](images/02-set2-terminals.jpg)

第二套用的是**另外一组 CT 绕组**，回路号是 121（5031）和 171（5032），端子编成 1、1A、2、2A……同样交替排列。两套保护用不同的电缆、不同的 CT 二次绕组，一套回路出问题不影响另一套，这才是真正的双重化。

### 装置端子是成对的

把端子排两侧的线号都对上以后，规律一下就出来了：

![照片3：第二套端子排两侧的线号](images/03-set2-both-sides.jpg)

| 端子 | 电缆侧（右） | 屏内侧（左，去装置） | 作用 |
|---|---|---|---|
| 1ID1 | A121 | 1n-0201 | 5031 A 相，进通道 1 |
| 1ID1A | A171 | 1n-0209 | 5032 A 相，进通道 2 |
| 1ID2 / 2A | B121 / B171 | 0203 / 0211 | B 相，两个通道 |
| 1ID3 / 3A | C121 / C171 | 0205 / 0213 | C 相，两个通道 |
| 1ID4 / 4A | N121 / N171 | 0208 / 0216 | N 线，回各自的 CT |
| 1ID5 / 6 | A122（接在 5 上） | 0202 / 0210 | A 相两个通道的出口，黄片并接 |
| 1ID7 / 8 | B122 | 0204 / 0212 | B 相出口，黄片并接 |
| 1ID9 / 10 | C122 | 0206 / 0214 | C 相出口，黄片并接 |
| 1ID11 / 12 | N122 | 0207 / 0215 | N 线，黄片并接 |

装置每一相有一个电流线圈，线圈两头各占一个装置端子，所以是一进一出：0201 进、0202 出，0209 进、0210 出……两组 CT 各走各的通道，**在装置内部相加**用于保护计算。

### 黄色连接片才是汇合点

![照片4：屏内侧的黄色连接片](images/04-set2-yellow-links.jpg)

第二套的汇合点不在进装置之前，而是在**出装置之后**：两个通道的出口分别回到 1ID5 和 1ID6，被一块黄色连接片连在一起，合成的和电流从 1ID5 以 A122 接出去，送往安稳主机B。

这也解释了我一开始的疑惑：为什么进来的是两组（121 和 171），出去的却只有一组 122？因为两股电流在黄色连接片那里已经并成一股了。

![图3：第二套保护 A 相完整回路](images/fig3-set2-loop.png)

这种接法的好处是装置能**分别看到**边开关和中开关的电流，可以单独判断每组 CT 是否断线。

注意这里的"黄色短接片"其实是**连接片**：它连的是同一相的两个端子（A 连 A），作用是汇合，电流继续往下走。做安措时的"短接"，是把 A、B、C 和 N 连在一起，让电流原地绕回 CT。两件事用的可能是同一种小片子，意义完全不同。

## 六、电流怎么"分回去"

和电流经过安稳、录波，从 N122 回来，到了 N 线的汇合点，会分成两股：一股回 5031，一股回 5032。

我一开始担心会不会"分错"。其实不会，而且分得**一分不差**。

5031 那一整圈（从它自己出发，经过端子、装置、汇合点、下游装置、汇合点、N 线，回到它自己）是只属于它的封闭回路。CT 是电流源，它逼着自己这条回路上每一处都必须等于 I₁。5032 同理，它那条回路上处处等于 I₂。汇合点只要求"进来多少、出去多少"对得上：I₁ + I₂ 进，I₁ + I₂ 出，刚好自洽。

对比上一篇的小鸟：

| | 小鸟分流 | 和电流分流 |
|---|---|---|
| 源的性质 | 电压源 | 电流源 |
| 怎么分 | 按电阻反比分 | 精确分回各自原来的大小 |

**电压源分流看阻抗，电流源分流看"它自己是谁"。**

## 七、中开关检修时，怎么隔离它的 CT

5032 转检修、两条线路继续运行时，要把 5032 的 CT 从和电流回路里拿出来。不拿出来，检修人员给 5032 CT 做通流试验，试验电流会串进运行中的线路保护，把好好的线路跳掉。

![图4：隔离 5032 CT 的正确位置](images/fig4-isolation.png)

要点：

1. **A、B、C、N 四个端子一起处理**。N 不断的话，检修侧再有一个接地点就成了两点接地，地电位差和试验电流会顺着 N 线串进运行回路。
2. **先短接、后断开**。先在电缆侧把 A、B、C、N 短在一起，CT 有了自己的通路，再断连片，整个过程 CT 都不会开路。恢复时反过来：先合连片，再拆短接线。
3. **短接点一定在电缆侧**。第一套的屏内侧就是汇合点，短在那里会把 5031 的运行电流一起短回去，保护几乎看不到电流，可能误动，也可能拒动。
4. **黄色连接片一律不动**，第一套 1ID8 上的接地点也不能动，它们都连着运行中的回路。
5. **动手前用钳形表卡一下**：5032 已经停电，电流应接近 0；5031 带负荷，应该有电流。**做完到装置里看采样**：5031 的负荷电流还在，没有差流告警。

一条线路第一套是 1ID2/4/6/8，第二套是 1ID1A/2A/3A/4A，共 8 个端子。两条线路就是 16 个。具体以本站二次安措票为准。

## 八、串接顺序：保护 → 安稳 → 录波

同一路和电流上串了三个装置。为什么保护在最前面？

先破一个误区：大家在同一个圈上，**圈上任何一处开路，所有装置都会断流**，排在后面并不会更"安全"。

排序的真正道理是**检修方便**：谁越常需要单独退出做试验，谁就往后排。退出末端的装置，只要在它前面做安措，前面的装置照常运行。保护对连续运行要求最高、很少单独退出，所以离 CT 最近。

那安稳用和电流行不行？我查下来的结论是：

- 安稳要判断线路潮流、功角，本来就需要**这条线的电流**，3/2 接线里线路电流就是和电流，所以**用和电流在功能上是合理的**。
- 我没有找到一条明确的条文写"安稳不能用和电流"。更理想的做法是给安稳独立的 CT 绕组，但这属于设计原则，执行严格程度因设计年代而异。
- 真正要核实的是三点：**安稳的出口压板独立**、**CT 二次负荷没有超标**（串的装置越多负荷越重）、**安稳能单独退出做传动试验而不影响保护**。

## 十、今天纠正的几个错误认识

| 以前以为 | 实际上 |
|---|---|
| 101 是合闸回路 | 101 是直流正电源，合闸、跳闸回路要从正电源出发经过触点才出现 |
| 开关储了能，没控制电源也能分一次 | 储能只是机械能，跳闸必须给跳闸线圈通电；能跳是因为还有第二组跳圈和第二组控制电源 |
| 电流回路编号都在 400～599 | 我们站电流回路用 111、181 这类编号，以本站图纸为准 |
| 隔离 CT 只拆 A、B、C | N 也要断，否则可能两点接地 |
| 看颜色判断回路 | 看线号，JD 段红蓝线是照明 |
